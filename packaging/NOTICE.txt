Security note
-------------
DeepSeek Harness can execute local commands and edit files in the chosen
workspace. Only use trusted models, plugins, and projects. The local Web UI
binds to 127.0.0.1 by default. The data\dsh-home folder may contain API keys
and private sessions — treat it as sensitive.
